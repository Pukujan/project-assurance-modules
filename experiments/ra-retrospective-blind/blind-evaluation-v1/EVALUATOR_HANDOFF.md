# Blind evaluator handoff

Start here in a fresh evaluator session.

1. Read `README.md` in this directory.
2. Read `SCORING_RUBRIC.md`.
3. Read only `candidate-alpha/EVIDENCE.md` through `candidate-epsilon/EVIDENCE.md` from this directory.
4. You may inspect the finished `Pukujan/research-assurance` reference project after candidate outputs have already been frozen.
5. Do not inspect any other branch/path in `Pukujan/project-assurance-modules`, prior evaluator results, candidate manifests/attestations, or Git metadata that could reveal model/vendor/harness/condition identity.
6. Score semantic planning obligations, not textual similarity to the reference.
7. Write and freeze `BLIND_EVALUATION.json` and `BLIND_EVALUATION.md` before any identity reveal.
8. Stop after freezing. Do not request identities. A later session/turn will reveal them for vendor-bias analysis.

A valid blind evaluation must not alter scores after the identity reveal.
